Silver Night

A 2D Unity game built from scratch — shipped as a playable WebGL build. I designed the gameplay systems in C# and created the sprites in Photoshop.

Play Web Build Gameplay Video GitHub Repo
Unity • C# Photoshop (sprites) WebGL

Goal

Build and ship a complete game in Unity by learning game development fundamentals and implementing core systems end-to-end.

What I built

  • Core gameplay: responsive movement + collision handling
  • Game flow: menus → gameplay → win/lose states
  • Level/scene flow: transitions and progression logic
  • Assets: created sprites/UI visuals in Photoshop
  • Deployment: published a WebGL build for browser play

Challenges & solutions

  • Getting movement to “feel right”: iterated on acceleration, jump timing, and collision tuning.
  • State management: separated menu/gameplay/end states to keep logic maintainable.
  • WebGL deployment: configured resolution + fullscreen so it fits screens without stretching.
